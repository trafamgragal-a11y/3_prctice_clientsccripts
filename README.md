# Справочник пользователей (Practical Task 3B)

Небольшое интерактивное веб-приложение на чистом HTML/CSS/JS, которое
загружает пользователей с публичного REST API
[jsonplaceholder.org](https://jsonplaceholder.typicode.com), позволяет
фильтровать их по имени и просматривать первые три публикации выбранного
пользователя.

## Технологии

- HTML5 — семантическая разметка, без фреймворков
- CSS3 — оформление (тёплая палитра, адаптивная сетка карточек)
- Vanilla JavaScript (ES2017+) — `fetch`, `async/await`, работа с DOM
  через `addEventListener`, `createElement`, `textContent`
- Никаких сборщиков, зависимостей и `npm install` — достаточно
  открыть файл в браузере

## Запуск приложения

1. Распаковать архив.
2. Открыть `index.html` двойным кликом в браузере
   (Chrome, Firefox, Edge, Safari — любой современный).
3. Интернет-соединение обязательно: данные приходят с
   `https://jsonplaceholder.typicode.com`.

Сервер, сборка и локальный хостинг **не требуются** — приложение
работает как статическая страница.

## Как пользоваться

1. Нажать **«Загрузить пользователей»** — на странице появятся
   10 пользователей (имя, email, город).
2. В поле **«Поиск по имени»** начать вводить текст — список
   фильтруется мгновенно, без нового HTTP-запроса, регистр не важен.
3. У любого пользователя нажать **«Показать публикации»** — в
   отдельной области отобразятся заголовки и тексты первых трёх
   публикаций этого пользователя.
4. Поле поиска можно очистить — вернутся все загруженные
   пользователи.

## Особенности реализации

- **Кэширование данных в памяти.** После первой загрузки массив
  пользователей хранится в переменной `allUsers`; поиск фильтрует
  именно его, а не делает повторные запросы к серверу.
- **Обработка ошибок.** Каждый `fetch` обёрнут в `try/catch/finally`;
  `response.ok` проверяется вручную, чтобы отличить HTTP-ошибку
  (404, 500 и т. п.) от сетевого сбоя.
- **Повторная попытка.** Отдельной кнопки «Retry» нет: после любой
  ошибки кнопка снова активна — достаточно нажать её ещё раз.
- **Безопасная вставка данных.** Все данные с сервера вставляются
  через `textContent`, а не `innerHTML`, — это исключает XSS.
- **Раздельные области.** Список пользователей (`#users-list`) и
  публикации (`#posts-area`) находятся в разных блоках страницы,
  как и требует задание.

## Известные ограничения

- Приложение рассчитано на работу с публичным API
  `jsonplaceholder.typicode.com`; при отсутствии интернета или
  блокировке домена появится сообщение об ошибке — это ожидаемое
  поведение, предусмотренное требованием об обработке сетевых сбоев.
- `localStorage` намеренно не используется (по условию задания данные
  не нужно сохранять между перезагрузками).
